## light —— 宝石展示台

**Gemstone Display Stand with Light Slot** · 可装入 **直径 24mm 小灯** 的宝石展示台

一个圆柱形展示台，顶部预留了 Ø24mm 的灯位，可以装入常见的 24mm 圆形小灯（LED 灯芯 / 小夜灯模块等）。把小灯放进去，再把宝石、水晶或矿石放到台面上，光就会从下往上透过去，把宝石的净度和色彩照出来。

比起打一束顶光，从底部透光更容易看清宝石内部的包裹体和颜色层次，拍视频或直播的时候效果会比较明显。灯位尺寸是量着模型导出的，通用性还可以。

### 文件说明

```
light/
├── shell.stl    外壳主体（含 Ø24mm 灯位）
└── frame.stl    外框
```

两个件配合使用，分别打印后组装。

### 尺寸参数

| 项目 | 数值 |
| --- | --- |
| 外形直径 | Ø100 mm |
| shell.stl 高度 | 35 mm |
| frame.stl 高度 | 50 mm |
| **灯位直径** | **Ø24 mm** |
| shell 体积 / 耗材 | 约 15.2 cm³（PLA 约 19 g） |
| frame 体积 / 耗材 | 约 17.9 cm³（PLA 约 22 g） |

> 以上尺寸由 STL 文件实测得出（外形 Ø100mm 与 Ø24mm 灯位均已在模型几何中核对）。

### 打印建议

- **层高**：0.2 mm，圆柱面和灯孔精度要求不高，常规设置即可
- **壁数 / 填充**：2–3 层壁 + 15% 填充，够用且省料
- **支撑**：不需要，两个件都是竖直面朝上，直接打印
- **材料**：PLA 或 PETG 都行。**如果想让灯更透亮，建议用透明或半透明耗材**（例如透明 / 自然色），透光效果比纯色好很多；纯色件也可以，只是亮度会打折
- **尺寸微调**：不同机器收缩不一样，如果小灯装进灯孔后偏紧，可以在切片软件里把 XY 补偿调大 0.2–0.3 mm，或者稍微打磨一下孔壁

### 使用

1. 分别打印 `shell.stl` 和 `frame.stl`
2. 把 Ø24mm 小灯装入灯位
3. 装上外框，把宝石放在台面上即可
